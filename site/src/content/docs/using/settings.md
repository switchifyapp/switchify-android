Open **Settings** from Switchify's home screen. It has four tabs, and remembers the one you were on.

## General

| Section | Contains |
| --- | --- |
| **Input** | Switches, Switch Hold, Switch Stability, Camera Settings. See [Connect a switch](/get-started/connect-a-switch/). |
| **Account** | Sign in, or your account. See [Pro and your account](/pro-and-account/). |
| **Usage** | Usage Statistics (below). |
| **On-device AI model** | Download or delete the model for the AI features. See [Pro and your account](/pro-and-account/). |
| **Behaviour** | Pause Settings (below). |
| **Gestures** | Advanced Gestures, Gesture Patterns, Scrolling Settings. See [Gestures and actions](/using/gestures-and-actions/). |
| **Menu** | Favourite Apps, Menu Customization, Menu Size, Menu Transparency. See [The menu](/using/the-menu/). |

## Scanning

| Section | Contains |
| --- | --- |
| **Access Techniques** | Item Scan, Point Scan or Radar; App-specific scanning; Access Technique Settings with a tab for each technique. |
| **Scanning Mode** | Auto or Manual, then Scan Speeds, Auto Scan Settings or Manual Scan Settings. |
| **Scan Appearance** | Scan Color. |

All of these are described on [Scanning](/using/scanning/).

## Selection

| Setting | What it does |
| --- | --- |
| **Auto select** | Tap the item after a delay instead of opening the menu. Press again during the delay to open the menu. |
| **Auto select delay** | 0.1 to 100 seconds. |
| **Directly select keyboard keys** | Type keys as soon as they are selected. See [Keyboard](/using/keyboard/). |
| **Assisted selection** | Select the closest interactive item to where you selected. |

## Pause

**Pause Switchify** (from the menu, or a switch set to that action) stops Switchify reacting to your switches so you can use them with another app, for example a communication app with its own switch scanning. Under **Settings → Behaviour → Pause Settings**:

- **Pause Timeout**: how long before Switchify resumes by itself, 30 seconds or 1, 2, 3, 4 or 5 minutes. The default is 30 seconds. Switchify resumes once no switch has been pressed for that long.
- **Hold to Unpause Duration**: hold any switch for 0.5, 1, 2, 3 or 5 seconds during a pause to resume straight away.

## Usage statistics

**Settings → General → Usage Statistics** shows switch presses (external and camera, with a breakdown by switch), menu opens and top menus, and activity over time, for today, the week, the month or all time. The statistics are stored on the device and you can clear them at any time.
