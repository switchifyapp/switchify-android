---
title: Keyboard
description: How Switchify scans the on-screen keyboard you already use, how to leave it, and the Directly select keyboard keys option.
---

Switchify does not have a keyboard of its own. When a text field has focus and Android shows its on-screen keyboard, Switchify scans that keyboard's keys like any other items. This works with the keyboard you have installed.

## Typing

The keys are scanned with your item scan settings, so with Row/Column Scan on, the rows highlight in turn; press Select on a row, then on a key.

By default, selecting a key opens [the menu](/using/the-menu/) at that key, like any other item. Turn on **Directly select keyboard keys** under **Settings → Selection** to type the key straight away instead. With this on, Auto select is bypassed while the keyboard is being scanned, so keys are typed as soon as you select them.

## Leaving the keyboard

While the keyboard is being scanned, each pass through the keys ends on a prompt: **Leave the keyboard? Press your switch now to escape.** Select it to go back to scanning the rest of the screen. The keyboard stays open.

Once you have escaped, a **Scan Keyboard** item appears in the menu so you can return to the keys.

## Typing on a PC

To type on a paired computer, use the Typing surface in PC control instead. See [Mouse, Typing and Window](/pc-control/mouse-typing-window/).
