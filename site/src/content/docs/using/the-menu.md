---
title: The menu
description: Switchify's own scanning menu of actions, its submenus, how pages and navigation work, and how to reorder or hide items.
---

When you select a point or an item, Switchify opens its menu there. The menu scans like everything else; press Select on the item you want. The highlighted item's name and a short description appear in a header above the grid, so long labels are never cut off.

## Main menu

| Item | What it does |
| --- | --- |
| **Back** | Go back to the previous screen. |
| **Home** | Return to the home screen. |
| **Scan Keyboard** | Return to scanning the on-screen keyboard after you have left it. See [Keyboard](/using/keyboard/). |
| **Tap** | Single tap at the chosen point. |
| **Gestures** | Open the gestures submenu. See [Gestures and actions](/using/gestures-and-actions/). |
| **Scroll** | Scroll up, down, left or right. |
| **Favourite Apps** | Open one of the apps you chose in Settings. |
| **Switch profile** | Change to another switch mapping profile. |
| **Gesture Patterns** | Record or play back a saved sequence of gestures. |
| **Device** | Device-level actions (see below). |
| **Settings** | Change access technique and toggle scan options (see below). |
| **Media Control** | Play or pause, previous and next track, and volume. |
| **Edit** | Cut, copy and paste in the current text field. Only the actions the field supports are shown. |
| **AI** | Reply Drafter and Screen Highlights. Pro features; see [Pro and your account](/pro-and-account/). |
| **Play/Pause media** | Pause or resume what is playing without opening a submenu. |
| **Pause Switchify** | Pause scanning so the switches can be used elsewhere. See [Settings](/using/settings/#pause). |

When the selected item offers its own accessibility actions, such as expand, collapse, dismiss, scroll or page actions, an **Actions** item appears too.

## Moving around the menu

Every menu page has navigation items: **Close menu**, **Previous menu** when you are in a submenu, and **Previous page** and **Next page** when there are more items than fit. A **Dismiss message** item appears when Switchify is showing a message at the bottom of the screen. A row of dots shows which page you are on.

## Customise the menu

**Settings → General → Menu → Menu Customization** lists the items of each menu in the order they appear. Drag them, use arrows, or use a select-and-insert mode to reorder, and tap the eye icon to hide items you do not use. Page markers show where each new page starts. You can filter the list by menu: Main Menu, Device, Volume Control, Gestures, Tap Gestures, Tap and Hold, Swipe Gestures, Pinch Gestures, Scroll, Media Control and Edit. Hidden items can be added back.

Also under **Menu**:

- **Favourite Apps**: the apps that appear in the Favourite Apps submenu.
- **Menu Size**: Standard, Large or Extra Large.
- **Menu Transparency**: see the content behind the menu.
