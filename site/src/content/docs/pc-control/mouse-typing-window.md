Once a PC is [paired](/pc-control/pairing/) and connected, the **Remote** tab in PC control shows a surface of buttons. Scan and select them with your switches like any other screen. Use the surface field at the top to change surface, and **Switch PC** to jump to another saved computer.

If the computer does not report a compatible control profile, Switchify asks you to update Switchify PC and reconnect.

## Mouse

| Section | Buttons |
| --- | --- |
| **Movement** | Move the pointer up, down, left, right and diagonally. |
| **Clicks and scroll** | Click, Double click, Right click, Start drag / End drag, Scroll up, Scroll down. |
| **Pointer speed** | Slower, Faster, with the current percentage shown. |
| **Move to monitor** | Left, Up, Down, Right. Only on a computer with more than one monitor. |

Movement and scrolling can repeat while held, if the computer has movement repeat on. A **Stop movement** or **Stop repeating** control appears while something is repeating; any other control stops it too. A switch press can also stop a repeat once Switchify is on and an external switch is set up.

## Typing

Choose **Type live** or **Write a draft** in PC control's Settings or on the surface itself.

- **Live**: text is sent as you type. If the computer does not support live typing, Switchify says so.
- **Draft**: nothing is sent until you choose **Send to PC**. **Clear** empties the draft.

**PC keys** sends Backspace, Enter, Escape, Tab and the arrow keys. If some text or an Enter did not reach the computer, Switchify offers to retry.

## Window

| Section | Buttons |
| --- | --- |
| **Modifiers** | Hold Ctrl, Alt, Shift or Start (Control, Option, Shift or Command on a Mac). A held modifier stays active until you select it again, use it in a shortcut, or the remote disconnects. |
| **Windows** | Next app, Previous app, Task view, Show desktop, Minimize, Maximize, Close window. |
| **Shortcuts** | Keys sent together with the held modifiers. |
| **Move pointer to monitor** | As on the Mouse surface. |

## Edit a layout

Each section's buttons can be rearranged. Choose **Edit layout**, then a section. While editing, buttons do not control the PC. Select a button to move or remove it, or a row or column handle to move, insert or remove rows and columns. **Choose action** adds any action from the catalogue: pointer movement, mouse buttons, scrolling, pointer speed, monitors, modifiers, windows, shortcuts, PC keys and draft text. **Reset to default** restores the section's original arrangement.
